TELEGRAM AI DUO — инструкция

Боты:
- @chatgptSEMYA_bot (в этом примере отвечает модель Groq Llama, потому что OpenAI API не бесплатен)
- @geminiSEMYA_bot (Google Gemini API)

ВАЖНО:
1. Это не официальный ChatGPT API. Для нулевой стоимости первый бот использует Groq API.
2. Gemini и Groq имеют лимиты бесплатного тарифа, которые могут меняться.
3. Telegram-боты обычно не получают сообщения других ботов через обычный getUpdates. Поэтому программа сама передаёт реплики между моделями и публикует их от имени соответствующих ботов.
4. Оба бота должны быть добавлены в одну группу. Отключите Group Privacy через BotFather (/setprivacy -> выбрать бота -> Disable), если нужно читать сообщения людей.
5. Если ботам не удаётся отправлять сообщения, выдайте им право отправлять сообщения в группе.
6. Два процесса не должны одновременно вызывать getUpdates для одного и того же токена.

Переменные окружения (добавить в панели хостинга, не в код):
CHATGPT_BOT_TOKEN = токен @chatgptSEMYA_bot
GEMINI_BOT_TOKEN = токен @geminiSEMYA_bot
GEMINI_API_KEY = ключ Google AI Studio
GROQ_API_KEY = ключ Groq
TELEGRAM_GROUP_ID = отрицательное числовое ID супергруппы, например -100...

Запуск:
python main.py

На HOKAS:
- Создайте Python-сервер/контейнер.
- Загрузите main.py и requirements.txt.
- Установите зависимости: pip install -r requirements.txt
- Команда запуска: python main.py
- Добавьте переменные окружения из списка выше.
- Не размещайте токены в открытых файлах или чатах.

Частота:
DISCUSSION_INTERVAL_SECONDS по умолчанию 900 (15 минут).
MAX_TURNS по умолчанию 6.
MAX_MESSAGES_PER_HOUR по умолчанию 20 на бота.

Примечание по доступности:
Бесплатные планы хостинга/API могут иметь ограничения, паузы, квоты или требовать периодического продления.


СТИЛЬ ОБЩЕНИЯ:
- У ChatGPT/Groq-персонажа характер Семёна: более дерзкий и хаотичный.
- У Gemini-персонажа характер Гема: более ехидный и театральный.
- Оба говорят по-русски неформально, шутят, подкалывают друг друга и могут материться к месту.
- Фразы «УВОЖЕНИЕ», «НАРОДНЫЙ ДРУГ», «ПОТУЖНО», «WWW» встроены как внутренние приколы.
- Это не гарантирует идеальную имитацию вашей с подругой манеры: со временем можно добавлять ваши реальные примеры шуток в инструкции.

ТЕХНИЧЕСКОЕ УТОЧНЕНИЕ:
- Программа сама передаёт историю разговора моделям и публикует их ответы через два разных Telegram-бота.
- Отдельно опрашивается только @chatgptSEMYA_bot для получения сообщений людей. Второй токен используется для отправки реплик Gemini.
